coasta.ng, live site

Coasta

Founder, live in Abuja

Reserved-seat commuting. Riders book a seat on their route, track the bus live and board with a ride code. Three separate apps (rider, driver and admin) built on one shared project.

  • Seat holds and an atomic waitlist, so concurrent bookings cannot race for the same seat. Subscribers get priority.
  • Pay-as-you-go, weekly and monthly plans through Paystack and Flutterwave, with automatic same-day refunds if a booking fails after payment.
  • Running late? The system releases the seat, tells the driver and moves the rider to the next bus. Geofencing switches routes inside a 300 m radius.
  • Smile Identity NIN checks for riders and drivers, Termii SMS and OTP, Firebase push, SOS alerts and traffic-aware ETAs on Google Maps.
  • Registered the company, led the rebrand, built the investor deck and pitched live at a national entrepreneurship competition.
React 19 / Vite / Supabase / PostgreSQL / Google Maps API / installable web app / coasta.ng
